# Byrohaa / بيروحاء

A publication-ready, Arabic-first storefront prototype for the Byrohaa modest-fashion brand.

## Edit products

Open `app.js` and edit the `products` array. Each product supports:

- `name` and `english`
- `price` in USD
- `category`: `new` or `signature`
- `tag`
- `image` for a real product image, or `art` for a built-in placeholder

Replace the two images in `assets/` with your final product photography using the same filenames, or update the paths in `app.js`.

## Important placeholders

- Sample prices are illustrative.
- EGP conversion currently uses a simple editable rate in `app.js` (`value * 50`).
- Shipping, returns, account storage, and payment gateway integration are prepared as the next implementation step after the brand approves the visual direction.
- Instagram and TikTok are footer placeholders ready for real links.

Open `index.html` in VS Code or a browser to preview.
